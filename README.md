# Запуск автотестов для разных языков интерфейса (Stepik, Selenium + Python)

Итоговое задание курса «Автоматизация тестирования с помощью Selenium и Python»:
набор тестов запускается для разных языков интерфейса, язык передаётся параметром командной строки.

## Состав

- `conftest.py` — опция `--language` и фикстура `browser`, которая запускает Chrome
  с нужным языком (`intl.accept_languages`).
- `test_items.py` — тест, проверяющий наличие кнопки добавления товара в корзину
  на странице товара.

## Запуск

```bash
pip install pytest selenium
pytest --language=es test_items.py
```

Параметр `--language` принимает код языка, например `es`, `fr`, `ru`.
В тесте есть пауза `time.sleep(30)` после открытия страницы — она нужна, чтобы
визуально проверить язык кнопки, например при `--language=fr`
(кнопка должна называться «Ajouter au panier»).
